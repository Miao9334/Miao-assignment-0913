# Why Are We Here?

## Introduction about myself
在开始回答Why Are we here（programmingcourse）这个问题前，我想先通过简单介绍我的背景来回答whyarehere（ime），本科时我的专业是平面设计/视觉传达。起初在入学前，我觉得平面设计这是一门很有用的学科，因为它可以通过对文字、图案、颜色的编排把信息直观地传输给人们。

可是在学习过程中，尤其随着科技的进步，平面化的表达好像处处都充满着限制和约束，它没办法让观众产生沉浸的感觉，从而进一步调动观众感官的互动。一切的想法都起源于但又拘泥于平面化的表达。因此我认为目前我对技术的掌握能力已经开始限制我的创意表达。这就是我选择ime的原因。

## My Experience On Programming
而在准备申请作品集的过程中，我也接触到了code。那是一个艺术装置，我希望通过触摸传感器控制灯带的开关。因为之前毫无相关的经验于是通过资料的查询和与ai的交流，我确定了大概的方案：使用arduino搭配uno board来连接传感器和灯带。在此过程中我让ai帮我生成了代码导入arduino，但在连接传感器和灯带时，不能保证每一次的实验都成功。我知道大概是编码出了问题，但是我根本看不懂编码，这让我很苦恼。最后我求助了有相关知识的朋友才最终解决这个问题。

从这个项目总结，我认为ai确实可以帮我们编写代码，但如果想保证项目顺利进行，作为设计师/艺术家的我们还是需要掌握编程知识。读懂代码、找出错误、修改错误。

## Code As An Artform
在课后，我观看了youtube视频。其中的一句话让我印象很深刻：the function of art is to hold a mirror up to nature。如果事先不告诉我视频中举出的许多例子是由代码生成的，我大概会猜测是使用adobe illustrator制作的，或是由AI工具生成的。

## Conclusion
技术与认知的关系/突破认知的边界 了解更多的可能性
